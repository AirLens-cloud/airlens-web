# Observatory display font

Subset woff2 files self-hosted for the OBSERVATORY instrument-world display type.
Ported from AirLens-platform `apps/web/public/fonts/observatory/` (2026-08-26) —
Martian Mono was NOT ported (porting brief decision #5 — obs mono uses JetBrains
Mono instead).

| `og-medium.woff2` | Overused Grotesk | 500 | SIL Open Font License 1.1 |

Free/open (OFL) — self-hosting/redistribution as part of this application is
permitted under the license terms. Subset covers Latin + common punctuation.
