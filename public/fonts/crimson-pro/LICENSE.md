# Crimson Pro (editorial voice serif)

Self-hosted variable-font woff2 files, downloaded from Google Fonts (fonts.gstatic.com)
for the Wave 4 Block 2 self-host (resolves porting-brief Δ1 — Crimson Pro was
previously *not* bundled; see tokens.css history). Latin subset only (this app's
Korean copy never renders in Crimson Pro — Hangul falls back to Inter/system).

| File | Family | Axis | License |
|---|---|---|---|
| `crimson-pro-variable-normal.woff2` | Crimson Pro | wght 200–900, normal | SIL Open Font License 1.1 — https://fonts.google.com/specimen/Crimson+Pro |
| `crimson-pro-variable-italic.woff2` | Crimson Pro | wght 200–900, italic | SIL Open Font License 1.1 |

Free/open (OFL) — self-hosting/redistribution as part of this application is
permitted under the license terms.
